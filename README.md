🍷 Wine Quality Analysis
📌 Descrição do Projeto

Este projeto realiza uma análise exploratória do dataset Wine Quality, com o objetivo de compreender quais propriedades físico-químicas influenciam a qualidade do vinho.

O dataset contém informações laboratoriais de vinhos da região portuguesa Vinho Verde, incluindo características químicas como acidez, teor alcoólico e densidade. A variável alvo representa a qualidade do vinho, atribuída por especialistas em degustação.

O objetivo principal deste projeto é explorar os dados, identificar correlações entre variáveis e compreender quais fatores podem impactar a qualidade do vinho.
